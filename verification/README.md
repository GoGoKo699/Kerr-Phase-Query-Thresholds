# Reproduce the finite checks

The scripts check finite arithmetic identities, spectra and ideal control matrices used in the scientific account. They are reproducible checks of specific ingredients. The written proofs and attributed number-theoretic results establish the adaptive, all-cap and asymptotic claims.

## Environment and commands

The suite was run with **Python 3.12.14** and **NumPy 2.3.5**. NumPy is the only external dependency; the arithmetic script itself uses the standard library. To use an isolated environment, run these commands from the repository root:

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r verification/requirements.txt
python3 verification/run_all.py
```

If the dependency is already available, only the final command is needed. Successful output is:

```text
PASS verify_arithmetic
PASS verify_access
PASS verify_physical
All finite checks passed and matched committed outputs.
Universal and asymptotic claims rely on the written proofs and cited theorems.
```

Each script can also be run directly to print its complete JSON report:

```bash
python3 verification/verify_arithmetic.py
python3 verification/verify_access.py
python3 verification/verify_physical.py
```

No script fetches data or reads private research records. The runner loads the three committed expected reports and compares their structures, exact values and floating-point results. The scientific assertions execute before that comparison. Expected reports are not regenerated by the runner.

### Exact arithmetic and spectral checks

The dynamic program enumerates **parallel total-photon-cap spectra**. For known linear phase it checks one through three uses at caps 2, 3, 4, 5, 6, 10, 20 and 40. For unknown common linear phase it checks one through four uses at caps 4, 7, 9, 15, 25 and 39, keeping each total-occupation sector separate.

The script separately finds and verifies all representative occupations in the guaranteed odd-sector bands for exposed totals 3, 9, 15, 25 and 39. It checks the exact-even-exposure run lengths in the tested range and the explicit total-24 run at frequencies 75 through 89. It also verifies the modulo-nine and modulo-four omissions underlying the simplest risk floors.

For each of five weighted schedules, the quadratic-form identity is checked on 343 occupation triples. Complete residue images are then enumerated modulo one suitable prime square. The observed counts are 21/25, 43/49, 111/121, 157/169 and 21/25 for the schedules stated in [the expected report](expected/verify_arithmetic.json).

These integer computations have no numerical tolerance. They verify the finite examples and the mapping formulas. They do not establish the existence of three-square representations for all caps, the divergent prime-product limit, or Bernays's asymptotic count; those are analytical proof ingredients.

### Timing and inverse access

The shortened-call check evaluates four coefficient pairs at each cap 9, 25, 101, 401 and 1601. It compares the finite POVM's outcome probabilities and risk with the derived adjacent-phase formula. The inverse-pair example is checked at three caps and two coefficient pairs each.

Probability normalization must agree within $`10^{-11}`$, and the measured and analytical risks within $`10^{-10}`$. The [expected report](expected/verify_access.json) records all 20 shortened-call cases and six inverse-pair cases. The asymptotic rates follow from the analytical inequalities, not from a fitted slope through these values.

### Full four-photon control sector

The physical script constructs the four-mode basis with total occupation four, of dimension $`\binom{7}{3}=35`$. The pair Hamiltonians select only their two participating modes and act for every permitted spectator occupation. Consequently the check can detect unwanted transitions outside the logical code.

It verifies the preparation amplitudes, all three logical edges, the echo commutator, absence of code leakage, the six-elimination Fourier compilation, and the actual two-grid measurement. All seven tested phases give risk $`(3-\sqrt5)/2`$ to numerical precision. The compiled Fourier matrix error was below $`3\times10^{-16}`$, its code leakage below $`7\times10^{-16}`$, and the physical-grid risk error below $`2\times10^{-16}`$ in the documented environment. Individual assertions use tolerance $`10^{-12}`$.

The same script verifies the cubic-risk formula for four residual coefficients at seven target phases. A fixed seeded set of normalized work vectors checks the general work-state risk identity; this is an algebra check, not a statistical simulation of device errors. It also performs 976 exact integer checks of the cubic Hadamard identity and 107 finite representation-predicate checks. The complete [expected physical report](expected/verify_physical.json) includes the compilation angles and all results.

## How to interpret a pass

The enumeration does not simulate every adaptive circuit. The adaptive converse is proved through its Fourier support, normalization and the cyclic discrimination bound. The finite matrix calculation likewise verifies the specified ideal gate construction; it does not demonstrate laboratory realizability, measured fidelity, an efficient fault-tolerant compilation, or a noise threshold for an entire device.

The coherent arithmetic algorithm uses the cited fixed-point search theorem. This suite checks its representation predicate and exact readout error identity, rather than numerically simulating its asymptotic execution. No data-driven extrapolation, QRAM access or external experimental dataset is used.

The cross-report comparator allows relative tolerance $`10^{-9}`$ and absolute tolerance $`10^{-10}`$ for floating-point values so harmless platform rounding does not count as a changed result. Exact integer and string fields must match. The pinned NumPy version remains part of the recorded environment.
